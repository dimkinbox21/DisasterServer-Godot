============================================================
 DISASTERSERVER v1101 — standalone Godot server (этап 2)
 Реплика BetterServer по визуалу и настройкам
============================================================

ЗАПУСК:
  Дважды кликни "START_SERVER.bat" — откроется окно 960x540.

ИНТЕРФЕЙС (как у BetterServer):
  - Лог-панель слева: (LIB.C:55): DISASTER V1101 и т.д.
  - Кнопки справа: BACK TO LOBBY / PRACTICE MODE /
    FORCE EXE WIN / FORCE ESCAPE (последние 2 — этап 3)
  - Низ: MAIN | OPTIONS | PLAYERS | INFO
    * MAIN    — лог и кнопки
    * OPTIONS — настройки из Config.json (клик по строке = правка)
    * PLAYERS — кто подключён (nid, ник, состояние, ping)
    * INFO    — версия, аптайм, состояние сервера

НАСТРОЙКИ (Config.json — создаётся при первом запуске, в
%APPDATA%\Roaming\Godot\app_userdata\DisasterServer v1101\):
  port        — порт (8606 по умолчанию, как у клиента)
  server_count, ping_limit, log_file, log_debug,
  anticheat, pride, motd — как у BetterServer
  Operators.json / Bans.json — тоже создаются.

ПОРЯДОК ТЕСТА (двое игроков):
  1. Запусти START_SERVER.bat
  2. Запусти ИГРАТЬ.bat у себя и у второго игрока
     (или два клиента на одном ПК)
  3. В меню: JOIN GAME → Enter (localhost уже вписан)
     * для игры по сети второй игрок вписывает твой IP
       (из Chansey: ipconfig → IPv4)
  4. Оба попадают в WAITING FOR ROUND TO END (чат работает:
     Enter → текст → Enter; .mute / .m — мут чата)
  5. Когда двое на сервере — лобби открывается автоматически
  6. В лобби: Z = READY, Enter = чат, X = выход в меню
  7. Когда все READY — голосование за карту (стрелки + Z),
     20 секунд
  8. Выбор персонажа (30 сек, EXE выбирается сервером случай-
     но): стрелки = выбор, Z = подтвердить (сервер проверяет,
     свободен ли персонаж — один персонаж = один игрок)
  9. PRACTICE MODE — кидает ТЕКУЩИХ игроков на карту "..."
     соло Соник.exe'ем (геймплей этап 3.1). BACK TO LOBBY
     возвращает всех в лобби.

ВАЖНО (античит-архитектура):
  Сервер АВТОРИТЕТНЫЙ: смерти/победы/выбор карт/кики решает
  сервер, клиент только шлёт события. Протокол пакетов 1:1
  с оригинальным (net_packets.gml).

Firewall: если клиенты не подключаются по сети — разреши
Godot.exe в брандмауэре (для localhost не нужно).

ЭТАП 3 (план): геймплей (net_state_game, 3518 строк), сами
карты, минигейм в waiting, результаты, practice mode.
