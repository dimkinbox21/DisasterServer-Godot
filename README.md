# DisasterServer — Godot port (сервер)

Отдельное серверное приложение для порта **Sonic.exe The Disaster 2D Remake** на Godot 4.7
(клиент: [Disaster2D-Godot](https://github.com/dimkinbox21/Disaster2D-Godot)).
Порт серверной логики оригинала (BetterServer): лобби, таймер раунда, синхронизация игроков, шипы/кольца.

## Запуск
1. Положи Godot 4.7 в папку `Godot\` (`Godot\Godot.exe`) — движок не хранится в репо.
2. `ЗАПУСТИ СЕРВЕР.bat`.

Подробнее — `ИНСТРУКЦИЯ СЕРВЕР.txt`.
